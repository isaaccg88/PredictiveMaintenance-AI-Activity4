# Notebooks

Esta carpeta contiene los cuadernos de Google Colab
utilizados para implementar y comparar los modelos
preentrenados de Hugging Face.

## Actividad 4

El notebook principal incluirá:

- Configuración de GPU.
- Instalación de dependencias.
- Carga de modelos y dataset.
- Inferencia.
- Evaluación de métricas.
- Comparación de latencia.
- Análisis de resultados.
